# Last-Mile Delivery Tracker

A comprehensive delivery management platform where customers and admins can create orders with auto-calculated charges, agents are assigned intelligently, and customers are notified at every step of the delivery journey.

## Features
- **Role-based Access:** Customer, Delivery Agent, Admin
- **Dynamic Pricing Engine:** Volumetric weight calculation, Zone-based pricing, B2B/B2C rates, COD surcharge.
- **Smart Assignment:** Manual and automatic nearest-available agent assignment.
- **Order Lifecycle:** Status tracking with immutable history.
- **Failed Delivery Handling:** Customer notifications, rescheduling, and agent reassignment.

## Tech Stack
- **Frontend:** React, Vite, TypeScript, Vanilla CSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL with Prisma ORM
